# TEN VAD (vendored)

This directory is a vendored, ONNX-Runtime-free port of
[TEN VAD](https://github.com/TEN-framework/ten-vad) for the ESP32-S3.

- Upstream: TEN Framework, Copyright (c) 2025 Agora.
- License: Apache License 2.0 with additional conditions. See `LICENSE`
  and `NOTICES`; the conditions restrict deploying it in ways that compete
  with Agora. Review before commercial use.
- Model: `tools/ten-vad.onnx` (309 KB, 302 KB weights).
- Weights: `weights.h`, generated by
  `python3 tools/export_ten_vad_weights.py`.

## What changed from upstream

- Removed the ONNX Runtime dependency (`aed.c`, `aed_st.h`, `ten_vad.c`).
- Replaced `AUP_MODULE_AIVAD` with `aivad_model.c`, a small float32
  implementation of the model graph:
  - 3-in/16-out separable convolution front end
  - two 64-unit LSTMs
  - 128 -> 32 -> 1 dense head with sigmoid
- Kept TEN VAD's front end unchanged: pre-emphasis, 1024-point STFT,
  40-bin mel filterbank, 3-frame context, pitch feature, and scoring.
- Sources are compiled as C by `build.rs` via the `cc` crate.

## Model contract

- Input: 16 kHz mono `int16_t`, 256 samples per 16 ms frame.
- Output: voice probability `[0,1]` and a thresholded flag.
- Runtime memory: model scratch is about 8 KB on the heap; weights are
  `static const` in flash.

## Verification

The host build of this port was compared against the upstream prebuilt
TEN VAD library on `testset-audio-01.wav` (720 frames): max absolute
probability difference was 7e-4, mean 7e-5.

To regenerate the weights:

```sh
python3 tools/export_ten_vad_weights.py
```
